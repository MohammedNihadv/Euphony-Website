## Tech Stack
This website is built completely from scratch using purely native web technologies to ensure lightning-fast performance, zero dependencies, and a perfectly tailored Neo-Brutalist aesthetic:
- **HTML5** (Semantic structure & Accessibility)
- **Vanilla CSS3** (Custom variables, Flexbox/Grid, brutalist box-shadows, animations)
- **Vanilla JavaScript** (Theme switching, OS auto-detection, Web Audio API demo player)
- **No Frameworks:** No React, Vue, or Tailwind. 100% lightweight.

## Features
- **Smart OS Detection**: Automatically identifies if the visitor is on Windows, macOS, Linux, or Android, and highlights the correct direct-download APK or AppImage.
- **3-Way Theme Switcher**: Instant toggling between Light Mode, Dark Mode, and a high-contrast AMOLED Black Mode.
- **Interactive Web Audio Demo**: A custom-built mini music player directly on the homepage that lets visitors test local audio playback.
- **Bulletproof Responsiveness**: A completely fluid layout with a sleek Animated Hamburger Menu drawer on mobile.

## Running Locally
Because there are zero dependencies, you can run this website instantly without installing any node modules or build tools:
1. Clone this repository.
2. Open `index.html` directly in your web browser.
3. *Optional:* If you want to use the Live Server extension in VS Code for hot-reloading during development, simply right-click `index.html` and select "Open with Live Server".
